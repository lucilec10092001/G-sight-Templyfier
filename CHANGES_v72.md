# Templyfier v72

- Replaces the technical row/column grid introduced in v71 with a visual Excel preview.
- Reproduces generated cell colours, bold text, alignment, merged cells and approximate column widths.
- Formats percentages and point gaps as they will be read in Excel.
- Evaluates Templyfier gap formulas for the preview when both source values are available.
- Hides raw formulas and technical Excel coordinates from the CMI.
- Keeps the preview optional, collapsed and limited for speed.
