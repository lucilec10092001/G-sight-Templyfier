# v81 - Spreadsheet-style multi-row editing

- Tick `Edit together` on several questions, then edit one selected cell to copy that value to every selected question.
- Applies shared edits immediately and refreshes the table so every updated row is visible.
- Supports shared Keep, type, metrics, variable/item, group, section, stage, split and KPI edits.
- Maps metrics safely across question items and refuses the shared edit if a selected question has no equivalent metric.
- Keeps ordinary unselected cell edits question-specific.
- Removes the separate shared-action form and its unnecessary extra click.
