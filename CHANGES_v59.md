# Templyfier v59

## Simpler metric selection

- Keeps presets for all seven question types visible: Standard, Strength, CATA, Listing, Bipolar, Preference and Project-specific.
- Shows the recommended preset even when no question of that type is currently detected.
- Replaces the separate question-specific metric editor with an editable **Metrics** dropdown on every table row.
- Applies the destination type's current preset when a CMI changes a question type in the table.
- Keeps multi-row selection for shared naming, grouping, section, stage, split and KPI changes only.

The calculation engine and Excel writer are unchanged.
