# Templyfier v98 - controlled Excel structure

- Automatic section suggestions remain visible and editable in the question table.
- Colored section headers remain disabled by default and appear only when the CMI enables **Show section headers in Excel**.
- **Section header** controls the large Excel blocks; **Item family** keeps related items such as Colour or Fragrance attributes together.
- A short pre-generation check reports the number of section headers, item families and families split across sections.
- If one item family is assigned to several sections, Templyfier silently consolidates it into one contiguous section and displays a non-blocking information message.
- The existing question order, metric, split, benchmark and workbook safety controls remain unchanged.
