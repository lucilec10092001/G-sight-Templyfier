# v78 - Repeated-product study support

- Accepts the same product code or fragrance in several distinct G-Sight positions for Paired, Monadic and CLT studies.
- Preserves repeated positions by occurrence instead of collapsing them to the first matching code.
- Allows pair-specific CMR codes to share a Fr-Land ID or formula identifier.
- Allows repeated displayed product names in Excel; an optional subtitle can still distinguish occurrences for readers.
- Keeps strict blocking for genuinely conflicting primary CMR codes and invalid Paired mappings.
- Applies an automatically detected benchmark to every matching occurrence of that product code.
