# Templyfier v104 - silent checks and useful diagnostics

- Removed the visible `Technical source checks` section when every source is coherent.
- Removed the redundant successful `Source check` caption.
- A source-control panel now appears only as **Files to check** when a blocker or meaningful warning exists.
- Blocking source issues still prevent generation and automatically expose the relevant details.
- Unexpected errors now provide a private downloadable diagnostic containing the support code, phase, exception and traceback.
- The diagnostic is shown only after an error and warns that file or worksheet names may be included.
- Replaced transport-unsafe bullet characters in source warnings with plain text markers.
