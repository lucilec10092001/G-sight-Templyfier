# Templyfier v75 validation

Validation covers the complete existing unit and Streamlit AppTest suite.

The release specifically checks that:

- the main journey still stops until both required file types are provided;
- setup remains a required gate before question review;
- question-type recipes and the editable question table remain available;
- the final preview is absent;
- advanced product and file-check labels use English;
- generation safeguards remain unchanged.

The final test result is recorded after the release suite completes.
