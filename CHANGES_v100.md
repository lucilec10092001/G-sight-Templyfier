# Templyfier v100 - structured question order

- **Change question order** now displays each Section header as a visible block.
- Item families appear as nested blocks inside their assigned section.
- Questions are indented under the corresponding family and section.
- A section or item-family header can be selected and dragged as one complete block.
- Before the order view opens, Templyfier consolidates sections and item families so the visual preview matches the Excel structure.
- After **Save order**, Templyfier normalises the order again; a section or family can no longer remain split in the generated workbook.
- Individual questions can still be reordered inside their assigned block. Section membership is changed in the main review table.
- Replaced component separators and drag handles with transport-safe text to avoid encoding artefacts.
