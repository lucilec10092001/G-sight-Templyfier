# Templyfier v60

## Consolidated Paired studies

- Detects one-workbook Paired exports where each valid result worksheet is a consumer split.
- Uses the worksheet title as the proposed split name and shows the workbook/worksheet source in the setup table.
- Accepts a different even number of active products, and therefore a different number of pairs, by split.
- Keeps Benchmark then Candidate ordering and calculates every delta as Candidate minus its paired Benchmark.
- Stores optional Benchmark/Candidate swaps per source worksheet instead of mixing the settings of worksheets from the same file.

Question detection, metric recipes and the Monadic engine remain unchanged.
