# Changes v94

- Restored the clean Excel layout used by the earlier presentable toplines: ordinary question names stay in the Variable column and only actual results such as Mean or Top Box appear in Metric.
- A broad optional item-family value such as Product or Fragrance can no longer collapse a multi-metric question.
- Automatic grouping is now conservative. Explicit batteries such as Color, Olfactive Attributes and Type of Freshness remain grouped; ambiguous isolated attributes and product benefits remain independent variables.
- Clarified the question-table labels: Item family is explicitly optional and Section is identified as the Excel section header.
