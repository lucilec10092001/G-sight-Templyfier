# Templyfier v93

- Question-table edits are saved automatically; the extra save button is no longer required.
- Saving a drag-and-drop order immediately refreshes the question model used for generation.
- Any question-level output change invalidates the previously generated download and asks for regeneration.
- Renaming the group or section of one grouped item updates the whole existing family, preventing fragmented attribute blocks and stale section headings.
